# 泡泡世界交互玩法 · 交接包（2026-10-31）

让泡泡世界从"只能看"变成"可以玩"。三个玩法都**不移动点云里的任何一个点**，所以不会再出现圆点变方块的问题。

**给实现的 agent：先读 `AGENT_TASK.md`。**

| 玩法 | 用户做什么 | 在哪 | 阶段 |
|---|---|---|---|
| 光的涟漪 | 捏一下手指，光从身边一层层向远处荡开 | 四个泡泡世界 | 第一步 |
| 接住飘落的东西 | 掌心朝上，接住雪花或巧克力碎 | 雪原、薄荷巧克力 | 第一步 |
| 心愿风铃 | 捏住手指在纸条上写字，放飞后永久挂在世界里 | 四个泡泡世界 | 第二步 |

## 包里有什么

| 路径 | 内容 |
|---|---|
| `AGENT_TASK.md` | 实现说明：每个玩法的触发方式、做法、数值、保存格式、测试和真机验收 |
| `WishChime/Models/` | 心愿风铃：糖果、自然各一只。`.fbx` 给 Unity，`.blend` 是源文件，另有 `.glb` 和渲染图 |
| `WishChime/Prototype/` | 心愿风铃网页原型的源文件 |
| `Catch/Models/` | 雪花、巧克力豆、薄荷糖碎（`CatchBits.fbx` / `.blend` / 渲染图） |
| `Audio/` | 16 个音效：涟漪 ×2、接住 ×6、风铃声 ×6、书写沙沙声（可循环）、放飞声 |
| `Voice/zh`、`Voice/en` | Moodi 的引导语音，中英各 9 句（MiniMax Cute Spirit，和其他 Moodi 语音同一个声音） |
| `Source/` | 生成模型、音效、切分语音的脚本，以及 MiniMax 原始整段录音和台词表 `lines.json` |

## 永久保存和以后的"心愿日记"

每只风铃存一条记录：笔迹、在这个世界里的位置、哪个世界哪一层、放飞时间，只存在设备本地。以后做"心愿日记"入口时，直接按时间读出这份数据即可，不用改格式。具体格式见 `AGENT_TASK.md`。
