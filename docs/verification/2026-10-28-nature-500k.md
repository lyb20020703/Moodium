# 自然泡泡世界 50 万点

用户要求从提供的原始扫描提升自然世界到 500000 点。

## 导出

- 输入：cca18ee63731606db19fc8f5852b03f5 (1).ply，1051081 条高斯记录。
- 可复用工具：tools/resample_nature_cloud.py（Python + numpy）。
- 使用旧 200000 点 MSPC 作为坐标参照，95967 对唯一 RGB 匹配求解原场景正交变换；最大坐标残差 0.00000372 m。
- 保留全部旧 200000 个中心，排除已用源点，从剩余扫描选出 300000 个中心。以不透明度和轻度近景权重采样，保留原场景最远距离；结果 500000 个中心全部不同。
- 点直径乘 sqrt(200000/500000)=0.63246，以更细密颗粒替代原来较大的覆盖片。
- 眼高保持 1.33897293 m，最大半径 72.06546 m；点由近到远排序。
- 未改全景图或糖果场景。

## 烘焙

- Unity 菜单 Moodium/Bubble World/Bake Nature Meshes，单独重烘焙自然世界。
- 20 层，每层 25000 点、100000 顶点，自动使用 UInt32 索引。
- 柔边颜色图更新为 4096×4096，保持 Bilinear、无 mipmap、RGBA 未压缩。
- 小泡泡显示前 11 层（275000 点），完全展开显示 500000 点。由于新增点偏重近景，初始泡泡也会更密集。

## 验证

- 二进制头和载荷一致：500000 点，9000020 字节；坐标/尺寸全部有限，尺寸为正，距离排序正确，中心无重复。
- Unity 编译、烘焙成功；相关 EditMode 测试 68/68 通过，0 失败、0 跳过。
- 测试验证自然世界 500000、糖果世界 200000，烘焙顶点数、32 位索引和颜色图尺寸。
- git diff --check 通过；糖果资源无差异。

真机尚需比较清晰度、帧率以及小泡泡出现时的开销。本次未修改远景全景图，因此远景背景纹理的分辨率限制仍然存在。
