## 1. 意图

现在能量只看“捏了多少下”：每下 +5，20 下满格。猛捏 10 秒就满，慢慢呼吸反而要 200 秒，奖励方向和疗愈目标正好相反。

这一版**不按世界分玩法**。演示时可能只来得及展示一个世界，所以**每个世界里都有三种模式**，放在桌上的三个按钮里切换：

| 模式 | 一句话 | 适合 |
|---|---|---|
| **自由模式** | 现在的玩法，随便捏，每下 +5 | 第一次玩、只想解压 |
| **节奏模式** | 光圈从外往里收，**碰到袋子的那一刻捏**，踩准加分最多，连着踩中有连拍 | 提起精神（低落、开心） |
| **呼吸模式** | **按住袋子 = 吸气，松开 = 呼气**，一圈柔光跟着呼吸从袋子边缘铺开、退回 | 慢下来（紧张、平静） |

三种模式共用同一条能量和同一套 100% 奖励，区别只在“怎么捏能量涨得最快”，以及看到什么引导。两个世界共用一套逻辑和素材，只换颜色（糖果粉、自然绿）和少量粒子（糖粒、种子）。

## 3. 设计原则

1. **奖励“怎么捏”**，不只是“捏了多少下”。但自由模式完全保留现在的手感。
2. **不失败、不惩罚**：没有“Miss”、扣分、倒计时。踩空只是普通的小反馈，任何玩法都能在 3 分钟左右满格（7.2 保底加速）。
3. **先看光，再看字**：引导首先靠光圈和潮汐的动效，看不懂才出文字，每句提示最多出现几次。
4. **袋子上方留给袋子**：所有引导 UI 都贴在桌面上、袋子四周，像给袋子加的光效；文字印在袋子前方的桌面上。袋子上方的空间不放任何东西（包括文字、光球、粒子），也不出现大面板。
5. **手部追踪丢了也能玩**：核心判断只靠“接触开始 / 结束”的时间。

## 4. 桌面模式按钮

效果图：`preview/render_free_candy.png`（看按钮最清楚）、`preview/modes_overview.png`。

### 4.1 位置与外观（详见 `layout.json → modeButtons`）
- 三个按钮平放在**桌面**上，在袋子靠近用户的一侧：行中心 `Z = 袋子长度/2 + 0.13 m`，`X = −0.085 / 0 / +0.085`，从左到右是 **自由 / 节奏 / 呼吸**。
- 每个按钮是一枚扁平的“玻璃圆片”：`mode_btn_base`（显示 0.08 m，含柔和投影，圆片本身约 0.064 m）+ 图标 `mode_icon_*`（0.03 m）+ 下方印在桌上的文字 `mode_label_*`（0.075 m 宽，往用户方向偏 0.056 m）。
- 朝向：平躺在桌面，文字正对用户（行的 +Z 方向取“相机前方在水平面上的投影”，在按钮出现时算一次，之后不跟着头转）。

### 4.2 状态
| 状态 | 表现 |
|---|---|
| 未选中 | 图标 55% 不透明，文字灰白 60% |
| 选中 | 圆片抬起 4 mm、放大 1.04；下面一圈 `mode_btn_selected_glow` 用世界主色；图标 100%，文字变主色 |
| 注视 / 手靠近 | `VisionOSHoverEffect` 默认高光 |
| 按下 | 圆片下沉 3 mm（0.12 s）回弹；一圈 `mode_btn_press_ripple` 从 1.0 扩到 1.5 倍、淡出（0.45 s）；一声轻“嗒” |
| 推荐 | 心情测试推荐的那个模式，按钮右上角一颗主色小圆点（`rhythm_combo_bead_full`，0.012 m） |

### 4.3 交互
- **直接用手指点**（指尖进入按钮碰撞体，约 0.07 × 0.02 × 0.07 m）或**看着按钮捏合**，两种都可以，沿用 `MoodiumSpatialInteractionController`。
- 按钮离袋子 13 cm（中间是桌面文字位，见 6.3），正常捏袋子不会误触。碰撞体只认指尖，不认手掌。
- 世界开始后 **1 秒**再淡入（0.4 s，同时上浮 1 cm），不和进入世界的动画抢注意力。
- 切换时，袋子前方的桌面文字位上出现一行模式名 `mode_toast_*`（0.14 m 宽，淡入 0.2 s、停 0.8 s、淡出 0.4 s），然后对应模式的引导出现。

### 4.4 切换规则
- **能量共用**，切换不清零。
- 切换时**连拍和呼吸状态重置**（节奏模式的连拍珠子清空；呼吸潮汐退回最薄）。
- **按住袋子时切换**：等这次松开后才生效，避免一口气算到两种规则里。
- 能量到 100% 之后按钮淡出，跟奖励流程一起走。

### 4.5 默认模式（读 `MoodCheckContext.PreSample`）
| 进入前的心情 | 默认模式 | 调整 |
|---|---|---|
| 没做心情测试 / 一般 neutral | 自由 | — |
| 开心 happy | 节奏 | 默认 |
| 低落 low | 节奏 | 判定窗口 0.22 → **0.28 s**，前 8 下连拍加成翻倍，先给“我做得到”的感觉 |
| 平静 calm | 呼吸 | 默认 |
| 烦躁 tense | 呼吸 | 呼气目标 5 → **6 s**（`exhaleOk = 6`），节奏更慢 |

默认模式就是“推荐”模式，按钮上有小圆点。用户手动切走后，心情预设不再生效。

## 5. 节奏模式

分镜：`preview/storyboard_rhythm.png`（6 帧）。效果图：`render_rhythm_candy.png`、`render_rhythm_hit_candy.png`。

### 5.1 玩法
- 89 BPM，**每隔一拍（约 1.35 s）一个“捏点”**。每拍都捏对捏袋子来说太急。
- 一圈光从 2.2 倍袋子大小往里收，**在光圈和袋子外框重合的那一刻捏下去**。
- 踩中：糖果 / 花叶迸发更大，音高随连拍升高，袋子后面的连拍珠子亮一颗。连续 8 下触发一次**冲刺**：外框闪白，迸一大把。
- 节奏感不好的人：**连续踩空 4 次后，节拍改成跟着他自己的节奏走**（跟随模式），之后看的是他稳不稳，不再要求对上音乐。

### 5.2 引导 UI 与动效（详见 `layout.json → rhythm`）
| 元素 | 素材 | 表现 |
|---|---|---|
| 目标外框 | `rhythm_target_outline`（虚线圆角矩形，比袋子每边大 2 cm） | 平铺在桌面，平时 60% 亮；进入判定窗口时亮到 100%，告诉用户“就是现在” |
| 收缩光圈 | 推荐：`RoundedRectBandMesh` + `rhythm_ring_band`（线宽不变）；简单做法：`rhythm_ring_circle` 直接缩放 | 每个周期从 2.2 倍收到 1.0 倍，缓入 `t^1.6`（越靠近越快，像被袋子吸过去）；透明度 0.25 → 1，越近越亮 |
| 踩中水花 | `rhythm_hit_splash`（浅色） | 从 1.0 扩到 1.35 倍、淡出，0.35 s；同时 14 颗 `squeeze_sparkle` 从袋子边缘**贴着桌面往外溅**（最高 3 cm，不飞到袋子上方）；袋子模型压扁到 0.84 |
| 连拍珠子 | `rhythm_combo_bead_empty / full` × 8 | 排在**袋子远离用户的一侧**的弧线上（不挡按钮和手）；踩中一颗亮起（0.6 → 1.15 → 1.0，0.25 s）；断掉时整排淡回空心（0.3 s） |
| 冲刺 | — | 每 8 连：46 颗亮片 + 外框闪白 0.2 s + 一段上行琶音 |
| 没踩中 | — | 普通小迸发，**不出现任何“失败”字样** |

**为什么光圈是圆角矩形**：袋子是长方形，圆形光圈碰到短边和长边的时间不同，用户会不知道该在哪一刻捏。光圈和袋子外框同形，四边同时重合，判定点一眼就清楚。

### 5.3 文字提示（`Composite/guide_hint_*`，印在袋子前方桌面的提示行，见 6.3）
| 时机 | 文字 | 次数 |
|---|---|---|
| 刚进入节奏模式 | 光圈碰到袋子时，捏一下 | 前 3 个捏点 |
| 连续 6 下都在 0.55 s 以内 | 慢一点，跟着光圈，糖果会更多（自然世界：花会开得更多） | 每次进入模式一次 |
| 进入跟随模式 | 节拍开始跟着你的节奏走了 | 一次 |

### 5.4 计分（每次接触开始时结算一次）
```
e      = 离最近捏点的时间差（秒）               // 跟随模式下 = |本次间隔 − 预测间隔|
a      = clamp01(1 − e / 窗口)                  // 窗口 0.22 s；跟随模式 0.34 s
连拍   = a > 0 ? 连拍 + 1 : 0
倍率   = 1 + 0.06 × min(连拍, 8)                 // 最高 1.48
防猛捏 = 间隔 < 0.55 s ? 0.25 : 间隔 < 0.85 s ? 0.6 : 1
能量   = (0.6 + 1.25 × a + (握合 ≥ 0.6 ? 0.3 : 0)) × 倍率 × 防猛捏
         + (连拍是 8 的倍数 ? 2.0 : 0)
能量  ×= 保底加速(已用时间)
```
跟随模式：预测间隔用指数平均（旧 0.7 / 新 0.3），每次捏都把节拍起点重设到这次捏的时间，间隔限制在 0.9–2.2 s。光圈也跟着这个预测间隔收缩。

“握合”是五个指尖到掌心的平均距离（按这个人张开手时归一化），手指被袋子挡住时拿不到，按 0 算。它只是小加分。

| 参数 | 默认 | 说明 |
|---|---|---|
| `bpm` / `beatsPerSqueeze` | 89 / 2 | 每隔两拍一个捏点 |
| `window` / `assistWindow` | 0.22 / 0.34 s | 判定窗口 |
| `base` / `rhythm` / `strength` | 0.6 / 1.25 / 0.3 | 基础 / 踩点 / 用力 |
| `comboStep` / `comboCap` | 0.06 / 8 | 连拍加成 |
| `rushEvery` / `rushBonus` | 8 / 2.0 | 冲刺 |
| `spamHard` / `spamHardMult` | 0.55 s / 0.25 | 猛捏 |
| `spamSoft` / `spamSoftMult` | 0.85 s / 0.6 | 偏急 |
| `adaptMisses` / `adaptMin` / `adaptMax` | 4 / 0.9 / 2.2 s | 跟随模式 |

### 5.5 节拍从哪来
- **糖果世界**：用 BGM 的实际播放时间对齐：节拍相位 = (`TryGetBackgroundMusicTime` − `beatOffset` − `inputLatency`) / 节拍间隔。不要用 `Time.time`，音乐一卡就会错位。
- **自然世界**：BGM 没有稳定节拍，**用配置的 BPM（默认 89，可改成更舒缓的 72）自己计时**，每个捏点配一声很轻的木鱼 / 水滴声，让耳朵也能跟上。以后可以加一条专门的节拍音轨。
- `beatOffset`（第一拍在音频里的位置）要在 Unity 里听一下再填，默认 0。89 BPM 是算法估的，接入前用耳朵确认一次；如果实际是 178 BPM，把 `beatsPerSqueeze` 改成 4。
- `inputLatency` 默认 0.05 s，补偿手部追踪延迟。

## 6. 呼吸模式

分镜：`preview/storyboard_breath.png`（7 帧）。效果图：`render_breath_in_nature.png`、`render_breath_out_nature.png`、`render_breath_in_candy.png`。

### 6.1 玩法
- **按住袋子 = 吸气**（约 4 秒），**松开 = 呼气**（约 5–6 秒），差不多每分钟 6 次，是放松练习里常见的慢呼吸节奏。
- **袋子上方不放任何东西**。袋子是视线的主角，引导全部贴在桌面上、袋子四周，像是袋子“在呼吸”时给桌面带出来的光。
- 一圈柔光像潮水一样**跟着用户的呼吸**从袋子边缘铺开、再退回。它不是节拍器：按住才铺开，4 秒铺到最远；松开后 5 秒慢慢退回，退到最薄就可以再吸一口气了。
- 约 9 口气满格，正好是一次 1.5 分钟左右的呼吸练习。

### 6.2 引导 UI 与动效（详见 `layout.json → breath`）
所有轮廓都贴着袋子的外形（圆角矩形，和节奏模式的外框同形），用同一个 `RoundedRectBandMesh`（`reference/RoundedRectBandMesh.cs`）生成。

| 元素 | 素材 | 表现 |
|---|---|---|
| **呼吸潮汐** | `breath_tide_band`（外缘一道亮“浪头”，往里逐渐变淡） | 平铺在桌面，从袋子边缘往外。空闲时 1.2 cm，每 4 秒轻轻起伏一下，告诉用户它是活的；吸气时 `easeInOutSine` 铺到 **6.5 cm**，越来越亮；呼气时同样的曲线退回 |
| **轮廓进度光** | `rhythm_ring_band` + 两颗 `breath_trace_head` | 一条很淡的底线一直贴在袋子外 2 cm。按下时**两颗光点从靠近用户那一侧的中点出发，沿着袋子轮廓往两边走**，4 秒后在袋子后方相遇，整圈闪白 0.15 s、迸出一小把光点。呼气时光线从后方倒着收回 |
| **呼气涟漪** | `rhythm_ring_band` | 只在呼气时出现：松开那一刻一圈，之后每 1.2 s 一圈（最多 3 圈），沿桌面从袋子边缘往外扩到 12 cm，同时淡出（2.4 s）。像一口气呼出去在水面上荡开 |
| **吸气光点** | `breath_mote`（+ 桌面上一小团 `breath_mote` 光晕） | 每秒 15 颗，从袋子外 7–16 cm 的桌面上出现，**贴着桌面**（离桌 0.2–1.2 cm）被吸向潮汐的浪头 |
| **呼气粒子** | 自然：`breath_mote_seed`（蒲公英种子）；糖果：`breath_mote_sugar`（糖粒） | 每秒 9 颗，从袋子边缘出发，**沿桌面往外飘**，最高只升到 4 cm，轻轻摇摆后淡出（2.6 s）。**不会飘到袋子上方** |
| **大字** | `breath_text_inhale / exhale_*` | 印在**袋子前方的桌面上**（见 6.3），按下时“吸气”淡入（0.4 s），松开换成“呼气”；透明度跟着潮汐在 0.75–1.0 间起伏，**不闪烁** |
| **呼吸计数** | `breath_count_dot_empty / full` × 9 | 大字下方一排平放在桌上的小点，每完成一口完整呼吸亮一颗，满 9 颗约等于满格 |
| 袋子模型 | — | 吸气时压扁到 0.9（只是视觉，真实的是用户手里的袋子） |

声音：吸气时环境音轻轻升起；松开时一声风铃，呼吸质量越好音越亮。

### 6.3 桌面文字位（所有模式共用，详见 `layout.json → tableTextSlot`）
文字不浮在空中，而是**印在袋子和模式按钮之间的桌面上**，像一张平放的小卡片，远端抬起 **30°**，让坐着的人看得清。卡片固定朝向用户，不跟着头转。

| 行 | 离袋子前沿 | 宽度 | 内容 |
|---|---|---|---|
| 大字 / 模式名 | 4 cm | 0.18 m（模式名 0.14 m） | 吸气 / 呼气；切换模式时的“呼吸模式”等 |
| 计数点 | 6.4 cm | 平放 | 9 颗 |
| 提示 | 8 cm | 0.24 m | 下面这些句子 |

### 6.4 文字提示（`Composite/guide_hint_*`）
| 时机 | 文字 | 次数 |
|---|---|---|
| 进入呼吸模式、还没按 | 准备好了，就按下袋子 | 直到第一次按下 |
| 按住中 | 按住袋子，慢慢吸气 | 前 2 口气 |
| 松开后 | 松开袋子，慢慢呼气 | 前 2 口气 |
| 按住超过 6 秒 | 可以松开了，慢慢呼气 | 每次进入模式一次 |
| 连续 3 次按住都不到 1.2 秒 | 可以按久一点，跟着光慢慢吸气 | 每次进入模式一次 |

### 6.5 计分
```
按住期间（每帧）：
    速率 = 按住 ≤ 4 s ? 0.5/s : 按住 ≤ 6 s ? 线性降到 0 : 0
    能量 += 速率 × dt

松开时：
    q = 梯形(按住时长；1.2 → 3.0 升到 1，5.5 → 8.0 降到 0)
    能量 += 5.5 × q                                 // 完整呼吸奖励

下一次接触开始时：
    p = clamp01((呼气时长 − 2) / (5 − 2))           // 呼气至少 5 秒拿满
    能量 += 3.5 × p                                 // 呼气奖励
    能量 += 0.8 × (呼气时长 ≥ 1.2 s ? 1 : 0.2)      // 保底，防猛捏

所有能量 × 保底加速(已用时间)
```
一口标准呼吸 ≈ 2.0 + 5.5 + 3.5 + 0.8 ≈ **11.8**。

| 参数 | 默认 | 说明 |
|---|---|---|
| `rate` | 0.5 /s | 按住期间的速率 |
| `inhale` / `fadeEnd` | 4 / 6 s | 潮汐铺满、轮廓光走满的时间；6 秒后不再积累 |
| `breathBonus` | 5.5 | 完整呼吸奖励 |
| `qLo` / `qOkLo` / `qOkHi` / `qHi` | 1.2 / 3.0 / 5.5 / 8.0 s | 呼吸质量梯形 |
| `exhaleBonus` / `exhaleLo` / `exhaleOk` | 3.5 / 2 / 5 s | 呼气奖励；`exhaleOk` 也是潮汐退回的时间 |
| `floor` / `floorMinGap` / `floorSpamMult` | 0.8 / 1.2 s / 0.2 | 保底与防猛捏 |

## 7. 共用规则

### 7.1 自由模式
保持现状：每次接触开始 +5，没有引导，只有现有的糖果迸发 / 藤蔓反馈。

### 7.2 保底加速
在世界里待满 **75 秒**后，节奏和呼吸模式的能量逐渐乘上 1 → 2.5（**150 秒**时到 2.5）。再随意的玩法也能在 3 分钟左右满格。自由模式本来就快，不加速。

### 7.3 阶段奖励
把已经写好的 `RewardSequenceController` 接上 `StageReached`，让 20 / 50 / 80 有回报。现在 1% 到 99% 之间几乎没有阶段感。

### 7.4 追踪丢失与边界情况
- **松开防抖**：握住真实袋子时手会轻微晃，接触体可能一帧进一帧出，把一口长呼吸切成几段。连续 **0.15 s** 不接触才算松开。
- **按住时追踪丢了**：给 0.3 s 宽限，期间找回就当一直按着；超过就按“丢失那一刻松开”结算。
- **两个袋子**（Object 和 Image 同时追踪）：只有一个计分器，两个袋子的接触都喂给它。
- **两只手同时捏**：算一次接触（第一只手开始，最后一只手结束）。

## 8. 模拟结果

`sim/sim.py` 每种玩法跑 40 次取中位数（脚本里 `candy` = 节奏模式，`nature` = 呼吸模式，`old` = 自由模式）：

| 模式 | 玩法 | 满格用时 | 捏了几下 |
|---|---|---|---|
| 节奏 | **跟着光圈** | **52 秒** | 38 |
| 节奏 | 节奏稳但没对上（进入跟随模式） | 95 秒 | 46 |
| 节奏 | 随便捏 | 165 秒 | 68 |
| 节奏 | 猛捏 | 143 秒 | 288 |
| 呼吸 | **按 4 秒、松 6 秒** | **91 秒** | 9 |
| 呼吸 | 按得太短（1–2 秒） | 116 秒 | 34 |
| 呼吸 | 猛捏 | 152 秒 | 307 |
| 呼吸 | 一直按着不放* | 212 秒 | 18 |
| 自由 | 猛捏 / 随便捏 / 慢慢呼吸 | 10 / 48 / 201 秒 | 20 |

\* 模拟里的这类玩家不理会提示；实际按到 6 秒就会提示松开。

结论：在节奏和呼吸模式里，**按引导去做是最快的**，猛捏反而慢，但谁都不会卡住。自由模式保留给只想解压的人。

调参：改 `sim.py` 顶部的参数后运行 `python3 sim.py results.json`；手感在原型里试（按住空格 = 捏住袋子）。

### 10.3 贴着袋子的光带
桌面上的线和光都用同一个 `RoundedRectBandMesh`（参考实现在 `reference/RoundedRectBandMesh.cs`，可以直接放进项目）：外形是指数 3.4 的超椭圆（和袋子、目标外框同形），UV 的 u 沿轮廓、v 横跨光带（0 内缘、1 外缘），可以只画一部分（`fill`，从靠近用户那一侧的中点向两边对称生长）。

| 用途 | 半尺寸 | 内缘偏移 | 宽度 | fill | 贴图 |
|---|---|---|---|---|---|
| 节奏光圈 | (袋子/2 + 0.02) × 缩放 | −0.003 | 0.006 | 1 | `rhythm_ring_band` |
| 呼吸潮汐 | 袋子/2 | 0.004 | 0.012 → 0.065 | 1 | `breath_tide_band` |
| 轮廓进度光 | 袋子/2 | 0.017 | 0.006 | 进度 | `rhythm_ring_band` |
| 呼气涟漪 | 袋子/2 | 0.005 → 0.12 | 0.004 | 1 | `rhythm_ring_band` |

材质：URP Unlit 透明，贴图 Wrap U = Repeat、V = Clamp。参考实现每次改参数都重建网格（几百个顶点，很便宜）；`fill` 每帧变化时数组长度会变，如果在意 GC，可以固定顶点数、把多余的顶点收拢到末端。

简单替代：节奏光圈可以先用 `rhythm_ring_circle` 贴在四边形上缩放，线会跟着变粗，但能先跑起来。

### 10.4 朝向
- **桌面上的东西都平躺**：按钮、外框、光圈、珠子、潮汐、轮廓光、涟漪、计数点。
- **桌面文字卡片**远端抬起 30°，固定朝向用户（按钮行出现时按“相机前方的水平投影”算一次），不跟头转。
- **只有小粒子朝向相机**（亮片、种子、糖粒），只绕 Y 轴转。
- 不再有任何浮在袋子上方的元素。

### 10.5 数据记录（给用户测试用）
在 `MoodCheckLog` 的同一个目录，每次世界访问写一份 JSON Lines。

**每次捏一条**：`visitId, world, mode, tStart, holdSeconds, gapSeconds, closure(可为空), beatError(节奏), combo(节奏), breathQuality(呼吸), exhaleQuality(呼吸), energyGained, assistMult`

**每次切换一条**：`visitId, t, from, to, energy`

**每次访问结束一条汇总**：`squeezeCount, timeTo100, modesUsed[], timeInMode{}, avgBeatAccuracy, breathCount, avgBreathCycleSeconds, adaptiveModeUsed, hintsShown[]`

这样可以分析：呼吸做得越好的人，前后两次心情测试的变化是不是越大。

## 11. 测试

**EditMode（纯计分类，不需要场景）**
1. 节奏：正好踩在捏点上 a = 1；偏差等于窗口时 a = 0；连拍到 8 时倍率 1.48，并触发冲刺。
2. 节奏：间隔 0.4 s 时乘 0.25；0.7 s 时乘 0.6。
3. 节奏：连续踩空 4 次后进入跟随模式；跟随模式里稳定的间隔得到高准确度。
4. 呼吸：按住 4 秒累计 2.0；6 秒以后不再增加。
5. 呼吸：按住 1.2 / 3 / 5.5 / 8 秒时，呼吸质量是 0 / 1 / 1 / 0。
6. 呼吸：呼气 2 / 5 秒时，呼气奖励是 0 / 满；间隔小于 1.2 秒时保底乘 0.2。
7. 保底加速：75 秒时 1.0，150 秒时 2.5；自由模式不加速。
8. 自由：每次 +5。
9. 模式切换：能量不变；连拍和呼吸状态清零；按住时切换，松开后才生效。
10. 默认模式：tense → 呼吸 + `exhaleOk = 6`；low → 节奏 + 窗口 0.28；没测 → 自由。
11. `SqueezeTracker`：0.1 s 的短暂离开不算松开；追踪丢失超过 0.3 s 按丢失时刻松开。
12. `RegisterPinch()` 仍然每次加 5（兼容旧测试）。

**真机**
1. 按钮：手指点、看 + 捏两种方式都能切换；正常捏袋子不会误触；字正对用户。
2. 节奏：光圈和外框重合时捏，是否轻快；节拍和音乐是否对齐（录屏逐帧看）。
3. 节奏：故意不跟拍，确认 4 次后跟着自己的节奏走。自然世界里节拍声是否够轻、够清楚。
4. 呼吸：握住真实袋子按 4 秒，看会不会被切成多段（防抖）。
5. 呼吸：完整做 9 口气，看满格是否在 90 秒左右；问被试是否放松，潮汐铺开 / 退回的速度是否舒服。
6. 层级：从不同角度看桌面，确认没有闪烁；桌面文字坐着看得清（太小就把 `tableTextSlot` 的宽度调大）。
7. 袋子上方：任何模式下，袋子上方都没有 UI 和粒子挡住袋子。
8. 三种模式都试猛捏，确认没有任何“失败”的感觉，只是慢。
