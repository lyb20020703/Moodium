# Moodi 模型挤出救援

依据 Moodium-MoodiSqueezeOut 的 README 和 codex-agent-prompt 实施；后者覆盖早期 plan 中仅自然世界启用、慢眨等旧设计。两个世界都使用开洞软模型及 Moodi v2。能量、语音规则、救援事件、散步及泡泡世界流程不改。

采用 ISqueezeProgressDisplay 隔离表现层，旧视频继续实现该接口。现有泡泡隐藏、视频粒子避让接口必须保留。模型层需要绑定 Mouth_Rig 和控制器才启用，缺资源退回视频。Moodi 由救援导演创建，挤出期间对齐骨架根与洞口世界矩阵，禁用自动朝向；弹出后恢复并交接散步向导。

资产导入须保留 Moodi 原 GUID、原五动作；新洞口控制器驱动进度／按压／Pop，喉管使用支持顶点色的 Shader Graph。按压弹簧、快速眨眼、落入和弹出颗粒按包内数值实现。进度只增不减，跨越全程不短于 3 秒。

验证需覆盖骨骼／动画数、旧动作长度、模型／视频选择、矩阵对齐、单次弹出、复位与事件顺序。编辑器生成两世界 0/50/100% 截图，真机蒙皮同步／性能单列未验证项。
