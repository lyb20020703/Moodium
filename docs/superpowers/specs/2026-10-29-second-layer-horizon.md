# 第二层泡泡世界坐标标准化

依据用户提供的 second-layer-fix.zip 和修复方案执行。已阅读旧交接包 README、调查记录、新 frame JSON，并检查两张点云／全景对照图：自然的松树、河道、落日及糖果的瀑布、塔、拱桥对应方向一致。

两个第二层使用各自 frame.json 的完整行向量变换，包含行列式为 -1 的手系转换。变换离线写入点位置，保持原全景图不变。自然眼高 0.369m，糖果 0.56m，保持原相机原点，不额外平移。各自仍为 500000 点、20 层烘焙网格。

实施中用户明确授权根据最终点云微调离线矩阵。最终采用固定源方向格和原始透明度进行可重复复核：糖果保留原矩阵，自然在原矩阵上合并约 1.01° 残余变换；两者最终均通过既定门槛。

数据和网格更新后，将运行时源坐标校正统一为 identity，删除估算的 .24/.79m 高度补偿与背景逆旋转。保留面向用户的整体 yaw、入场动画、风和手部扰动，以及所有并行 UI、藤蔓修改。

验证：离线对新 MSPC 再执行全方向配准，要求旋转误差 <1°、分数 >=0.55、与第二个不同姿态分差 >=0.15；Unity 测试四世界规范坐标、真实眼高、每个烘焙层抽样点中心一致及现有交互。第一层与两张全景文件用哈希确认未改变。真机地标截图、视差和性能无法由离线结果替代，明确单列待设备验收。
