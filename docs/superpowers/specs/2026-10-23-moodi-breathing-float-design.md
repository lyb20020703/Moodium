# Moodi 呼吸浮动动画设计

## 意图

让 `CandyWorldUI.prefab` 和 `NatureWorldUI.prefab` 中的 `Moodi meshy` 保持轻盈、有生命感的待机状态，同时不干扰世界 UI 的定位与交互。

## 目标

- `Moodi meshy` 持续进行平滑、循环的上下浮动。
- 浮动过程中叠加极轻微的整体缩放，形成呼吸感。
- 动画基于初始局部位置和缩放计算，长期运行不产生累计漂移。
- 两个世界 UI 使用同一个可复用组件和一致的默认参数。

## 非目标与限制

- 不修改模型骨骼、材质或现有 Animator 动画。
- 不改变 Prefab 根节点、UI 布局、碰撞或交互逻辑。
- 不依赖第三方 Tween 库。

## 方案比较

- Animator 动画片段：可视化直观，但会增加动画资源，参数复用与后续微调较繁琐。
- 独立脚本驱动（采用）：组件记录初始 Transform，用正弦曲线计算浮动和缩放；轻量、可复用、无漂移。
- 复用选关页 Moodi 控制器：已有浮动逻辑，但混合了触摸、粒子和选关职责，不适合世界 UI。

## 实现设计

- 新增 `MoodiBreathingFloat` MonoBehaviour，并挂载到两个 Prefab 的 `Moodi meshy` 实例。
- 默认参数：垂直浮动幅度 `0.01m`、周期 `2.8s`、缩放幅度 `1%`。
- 使用 `Time.unscaledTime`，保证 UI 场景的时间缩放变化不会让呼吸突然停止。
- 在启用时捕获基准局部位置与缩放；每帧根据同一正弦相位更新位置与缩放。
- 在禁用时恢复基准 Transform，避免重新启用时把偏移当作新基准。

## 验收标准

- 两个世界 UI 中的 Moodi 都能平滑循环浮动并轻微呼吸。
- 动画没有跳变、累计漂移或逐渐放大/缩小。
- 组件被禁用时模型恢复到 Prefab 原始位置与缩放。
- Unity 脚本编译无错误，并有编辑器测试覆盖关键计算或恢复行为。
