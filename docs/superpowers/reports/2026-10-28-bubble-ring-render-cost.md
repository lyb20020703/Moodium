# 光环最终渲染开销

主环、由外向内的停留填充、四个循环上升光点合并在每环一个动态 Mesh、一个材质、一个启用的 MeshRenderer 中。不依赖动态批处理，最多三个地面环和一个桌面环，共四个绘制对象；预计透明 pass 四次绘制，实际 GPU 次数需真机 Frame Debugger 确认。

每环 212 顶点、200 三角形，四环总计 848 顶点、800 三角形。每环每帧更新同一顶点数组，无光粒对象实例化、无 ParticleSystem、无新增独立 fill 绘制。所有环共享一张 32×32 RGBA32 柔光纹理（基础像素 4KB，无 mipmap），每环独立材质以支持各自等待进度及闪亮。StopAndClear 释放网格、材质、共享纹理和对象。

原 SpriteRenderer 保留用于已有 walk_floor_ring 资源的尺寸读取，但始终禁用，不提交绘制。几何主环使用细环面，光点使用共享程序柔光纹理；这是将填充与主环合批的实现调整。主环周期 3 秒、亮度 ±15%；光点每环固定四个，用尺寸渐变淡入淡出；填充向内增长，召唤闪亮 0.3 秒。

Unity 自带 Roslyn 与当前 Editor 程序集响应文件用于编译 API 检查；EditMode 测试与真机视觉/性能由集成终验执行。
